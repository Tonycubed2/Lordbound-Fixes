1. PLUGIN FIXES (Lordbound Fixes.esp)
------------------------------------------------------------------------
1. Masters of Highreach: Lanelle had no reaction line if Fardris's quest (LBMQ05) was the master quest you finished first, so the talk ended and stage 2 was never set; her generic line now covers that case
   Record changed: INFO 0505C4CE (topic DD_LBMQ01LordboundReaction, Lanelle: "You show great promise...").
   Removed its condition GetQuestCompleted(DD_LBMQ05) != 1, so this generic reply also plays when Fardris's quest is the one you finished first.
   The reply leads to Lanelle's proposal (INFO 0505C48F), whose script sets DD_LBMQ01 stage 2.
   In game: The Masters of Highreach - talking to Lanelle no longer ends early; console workaround no longer needed (setstage DD_LBMQ01 2).

2. Fill script properties the authors declared and use but left empty in the CK (quests, scenes, triggers, NPCs); empty properties make stages, scenes and triggers silently do nothing
   143 script properties on 106 records (full per-quest list in section 3).

3. Just Deserts: 'I had to kill him' / 'war criminal' replies required stage below 100, but killing Sergus sets stage 100, so options 2 and 3 dead-ended; now allowed up to stage 109
   Records changed: INFO 05096C91, 05096C92, 05096C8C (Mathieu's replies "I had to kill him..." / "war criminal").
   Condition GetStage(DD_ImpSQ01) < 100 changed to < 110.
   In game: Just Deserts options 2 and 3 now complete the quest (stages 112 / 111) instead of needing setstage.

4. The Lost Children: Lanelle's 'follow player to Garza' package only ran while she was inside Highreach, so she stopped following the moment you left town and the Garza scene trigger (needs both of you) never fired
   Record changed: PACK DD_OrcMQ05LanelleFollowPlayerToGarza (follow package).
   Removed condition GetInCurrentLoc(DDHighreachLocation) == 1.
   The scene with Garza (DD_OrcMQ05LanelleGarza) starts from trigger REFR 050A1973 only when both you and Lanelle are inside it.

5. Wrath: Garom's two optional answers at the end had no links back to the remaining choices, so you were dropped into a '...' loop; they now offer the other questions and 'You can count on me'
   Records changed: INFO 0506D392 (answer to "How could they have breached the passage?") and INFO 0506D382 (answer to "If I need to follow Garza...").
   Added reply choices (TCLT) linking to the other question and to "You can count on me" (DIAL 0506D381).

6. Kinslayer: after you spare Azgoth and pass Borgog's speech check, his reward line required stage 70 (the 'killed him' stage), so the quest never finished; the reward now also accepts the 'spared' stage 60
   Record changed: INFO 0507FC73 (Borgog reward line, topic DD_OrcNQ02BorgogBranchRewardTopic).
   Condition GetStage(DD_OrcNQ02) == 70 changed to >= 60.

7. Fill two more empty properties whose target records have slightly different names: Masters of Highreach 'LBMQ02' (Fulaz-Ahl's quest, used to tick his objective) and Tour of Duty's tracking spell (so M'zaad's tracking spell is removed afterwards)
   Records changed: QUST DD_LBMQ01 (script DD__QF_DD_LBMQ01_010173E2: property LBMQ02 = DD_LBMQ02 050173E1)
   and QUST DD_ImpMQ01 (script DD_ImpMQ01QuestScript: property DD_ImpMQ01InterrogatorTrackerSpell = DD_ImpMQ01InterrogatorTrackingSpell 05018869 "M'zaad's Spell of Tracking").

8. Door landing spots that were left sitting on top of the destination door: Garshakur Tailor exit (you appeared between the door and the wall) and the Putrid Cove Retreat entrance (you appeared facing the wall)
   Records changed (door teleport destination, XTEL):
   - REFR 050AEA57 (Garshakur Tailor interior door): landing moved 80 units in front of exterior door 050A8A0C, same facing.
   - REFR 050146C7 (exterior door into Putrid Cove Retreat): landing moved 90 units into the room from door 0503FBD8 and turned 180 degrees.

9. Grave of the First: Fulaz-Ahl's barrier-breaking scene only removed the barrier when his 'cast Thunderbolt at the barrier marker' package finished; if it never finished he stood there 'busy' forever. The barrier is now removed when that part of the scene starts (patched scene script waits a few seconds and ends the scene if it is still hung)
   Record changed: SCEN DD_LBMQ02FulazWyrmsbaneComment (0505C5D1). Phase 2 script fragment switched from "on phase end" to "on phase start".
   Script patched: F:\SkyrimSEMOModfolder\Lordbound Fixes\scripts\dd__sf_dd_lbmq02fulazwyrmsban_0105c5d1.pex (Fragment_2: wait 6 s, DisableBarrier, wait 4 s, stop scene if still playing).

10. Marks of a Fighter: Luzgrath asks for 'Stonebark Ale' and skulls, but only counted the vanilla Ale (rare in the valley) and the vanilla skull, not Lordbound's Stonebark ales or its own skull item; now any Stonebark drink or Ale, and either skull, count (and get taken)
   New records: FLST 06000800 LBFix_OrcNQ01Drinks (vanilla Ale + 16 Stonebark drinks), FLST 06000801 LBFix_OrcNQ01Skulls (vanilla skull 000AF5FD + Lordbound skull 0503FE57).
   Records changed: INFO 0507FC92, 0507FC9B, 0507FC9A (Luzgrath) - GetItemCount now counts the two lists; QUST DD_OrcNQ01 - properties LBFixDrinks / LBFixSkulls added.
   Script patched: F:\SkyrimSEMOModfolder\Lordbound Fixes\scripts\dd__qf_dd_orcnq01_0107fcd1.pex (stage 40 removes 1 drink and 12 skulls from the lists).

11. The Lost Legion added at the end of Lordbound: the faction-epilogue quest picks a journal entry for stage 100, and the Imperial entry's only condition (The Lost Legion at stage 270) was flagged OR with nothing after it, which leaves that entry's test open-ended; the stray OR flag is removed
   Record changed: QUST DD_FactionEpilogue (0504A171), stage 100 first journal entry: removed the OR flag from its only condition GetStage(DD_ImpMQ10) == 270.

12. Chasing Dreams: the 'Find 3 Brainrot Mushrooms (x/3)' and 'Find 3 Nightshade (x/3)' objectives showed '[...]/3' because their counter globals were never added to the quest's Text Display Globals list
   Record changed: QUST DD_LBMQ05 - added Text Display Globals DD_LBMQ05BrainrotCount (050AC965) and DD_LBMQ05NightshadeCount (050AC966).

13. Models that point at files Lordbound never shipped (red '!' in game), repointed to an existing model: Ashlorn rib-cap pieces (4 placed), a blue crystal in Ysgramor's Folly (typo'd path), a Highrock Stop roof, Aedron's armor spaulders on women, and the Liquor of Rooting bottle
   Records changed (model path):
   - STAT DrV_wrintdragonroomribcap01 -> Architecture\Whiterun\WRInteriors\WRCastle\WRIntDragonRoomRibCap01.nif (vanilla)
   - STAT DRV_BlueStaticCrystal -> Clutter\SoulGem\SoulGemGreater01.nif (vanilla; old path had the folder twice)
   - STAT DrV_FFHouse02RoofSnow -> Architecture\DrV_Frostford\BehindtheInnHouseSnowHeavy.nif (Lordbound file; old path had an extra \Snow\ folder)
   - ARMA DrV_EbonySpauldersAA female model -> armor\ebony\m\Lautasantenni_Spaulders2_1.nif (female file was never shipped)
   - ALCH DRVC_RootingLiquorBrew -> clutter\DrV_StoneBark\Brews\DrV_StonebarkCOBR.nif (Lordbound file)

14. Enigmatic Origins: the Jagged Crown on the skeleton atop the throne in the Revenant's version of Highreach was a real, lootable crown placed as loose loot; it is now a static decoration with the same model
   New record: STAT 06000802 LBFix_JaggedCrownStatic (model Armor\BoneCrown\BoneCrownGO.nif).
   Record changed: REFR 05032ED1 in DrVRevenantHighreach "The Epitaph" - base changed from ARMO ArmorBoneCrown (000DA750) to the new static.

15. Removed the three spell tomes (Golden Sparks, Disintegrate the Undead, Fierce Flames) from the developers' 'Core Team Armoury' test room: those spells' effects use textures Lordbound never shipped (purple effects); the tome references are now initially disabled
   Records changed (set Initially Disabled): REFR 050902C9 (Spell Tome: Disintegrate the Undead), REFR 0508DCD7 (Spell Tome: Golden Sparks),
   REFR 050960C0 (Spell Tome: Fierce Flames), all in cell DRVArms "Core Team Armoury" (only reachable with coc). The spells themselves are unchanged.

16. The Trial Road / getting back into the valley: the Mor Khazgur Passage gate is a key-only lock that Mogus's scene unlocks once (stage 30), but the tunnel cell resets, which relocks the gate and leaves you shut out of (or into) the Druadach Valley; the gate now carries the base game's defaultUnlockOnLoad script (DD_OrcIntro, stage 30), so it unlocks itself every time it loads once that stage is done
   Record changed: REFR 0509984C DD_OrcIntroTunnelGateREF in DrVMorKhazgurTunnel "Mor Khazgur Passage": added script defaultUnlockOnLoad
   (base game) with myQuest = DD_OrcIntro [QUST 0505C571] "The Trial Road", unlockStage = 30.
